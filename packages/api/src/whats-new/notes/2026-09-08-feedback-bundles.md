Review comments stay human conversation until you decide they are ready for an agent.

- Select individual comments or send every open comment from the review rail
- Undo a send for five seconds before an agent can claim it
- Follow each batch from queued to claimed, completed, or cancelled
- Keep replies in the original review threads
- Link the deployment that addresses a batch and add concise change notes

Interactive pages now open in **Experience** mode, where their controls behave normally. Switch to **Comment** mode when you want to select text or open anchored feedback.
