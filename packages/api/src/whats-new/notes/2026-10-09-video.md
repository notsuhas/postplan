Deploy an mp4, m4v, mov, or webm file and Postplan opens it in a video player.

- Seek anywhere without downloading the whole file
- Open the original or download it from the toolbar
- Comments on a video can insert the current `[m:ss]` timestamp, like audio

Files are still limited to 20 MB each.
